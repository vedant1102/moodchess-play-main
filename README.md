# ♟️ MoodChess Play

A **multiplayer chess application** built using modern web technologies. It allows two players to play together in real-time by sharing a unique join code, choose different timer presets, and experience an AI-powered move explanation system that helps users understand their decisions.

---

## 🚀 Tech Stack

This project is built using:

* **Vite** – for fast development and build setup
* **React (TypeScript)** – component-based UI framework
* **Tailwind CSS** – for modern, responsive styling
* **shadcn/ui** – for prebuilt, accessible UI components

---

## 🧠 Features

✅ Create or join a chess match using a unique code
✅ Real-time multiplayer gameplay
✅ Different timer presets (1m, 3m, 5m, 10m)
✅ AI move explanations for learning and improvement
✅ Clean, responsive, and intuitive UI

---

## 🛠️ Getting Started

Follow the steps below to set up and run this project locally:

### Prerequisites

Make sure you have the following installed:

* **Node.js** (>= 16.x recommended)
* **npm** or **yarn**

### Installation

```bash
# Step 1: Clone the repository
git clone <YOUR_REPOSITORY_URL>

# Step 2: Navigate into the project folder
cd moodchess-play-main

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The application will start on your local development server (usually at `http://localhost:5173` or similar).
